1. 전부 읽었나
   이 스킬 폴더에 파일이 몇 개 있나? 이름을 모두 적기
   (볼 곳: VS Code 탐색기에서 폴더를 모두 펼치기)

2. 설명대로만 하나
   이 스킬은 무엇을 하는 스킬인가? 한 줄로.
   top3.py 가 하는 일도 그 설명과 같은가?
   (볼 곳: SKILL.md 맨 위 description, scripts/top3.py)
   답: KOBIS 일별 박스오피스에서 특정 날짜의 1~3위 영화 제목을 알려 주는 스킬임. top3.py 도 KOBIS 일별 박스오피스 API 를 호출해 상위 3편의 순위와 제목만 출력하므로 설명과 같음.

3. 바깥으로 보내는 곳
   이 스킬이 내 컴퓨터 밖의 서버에 연결하는 곳이 있나?
   있으면 그 주소와, 무엇을 보내는지 적기
   (볼 곳: Ctrl+Shift+F 로 http 검색. 파일 이름과 줄 번호)
   답: 있음. scripts/top3.py 10~11행 BASE_URL = https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json (15행 requests.get 으로 호출). API 키(key)와 조회 날짜(targetDt)를 보냄. 주소가 KOBIS 공식 API 라 설명과 일치하고, 다른 곳으로 보내는 코드는 없음.

4. 키와 비밀
   키를 코드에 직접 적어 두었나? 키는 어디서 읽어 오나?
   (볼 곳: Ctrl+Shift+F 로 key 검색. 파일 이름과 줄 번호)
   답: 직접 적어 두지 않음. scripts/top3.py 8행 `from secret import API_KEY` 로 프로젝트 폴더의 secret.py 에서 읽어 옴 (7행에서 현재 작업 폴더를 import 경로에 추가).
