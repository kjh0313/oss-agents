# week09/tools.py 함수 설명 (notes_before)

`tools.py`는 KOBIS(영화진흥위원회) 오픈 API의 **일별 박스오피스** 데이터를 가져오는 도구 모음입니다.

## 공통 사항

- `requests`로 `BASE_URL`(`searchDailyBoxOfficeList.json`)을 호출합니다.
- API 키는 `secret.py`의 `API_KEY`에서 가져옵니다.
- 두 함수 모두 `key`, `targetDt`(조회 날짜) 파라미터를 보내고, 타임아웃은 10초입니다.
- 응답의 `boxOfficeResult.dailyBoxOfficeList`(영화 목록)를 사용합니다.

## 함수 목록

### 1. `get_boxoffice_rank_1(date)`

- **역할**: 해당 날짜 박스오피스 1위 영화 제목을 알려줍니다.
- **입력**: `date` (str) - 8자리 날짜. 예: `"20260824"`
- **반환**: (str) 1위 영화 제목. 예: `"오디세이"`
- **동작**: 목록의 첫 번째 항목(`movies[0]`)의 `movieNm`을 반환합니다.

### 2. `get_movie_audience(date, title)`

- **역할**: 해당 날짜 박스오피스에서 특정 영화의 관객 수를 조회합니다.
- **입력**:
  - `date` (str) - 8자리 조회 날짜
  - `title` (str) - 검색할 영화 제목
- **반환**: (str)
  - 찾은 경우: 천 단위 쉼표와 '명'이 붙은 문자열. 예: `"186,587명"`
  - 못 찾은 경우: `"'{title}' 은(는) {date} 순위에 없습니다."`
- **동작**: 목록을 순회하며 `movieNm`이 `title`과 정확히 일치하는 영화의 `audiCnt`를 정수로 변환해 포맷합니다.

## 참고 (관찰 사항)

- 두 함수가 같은 API 호출 코드를 중복해서 가지고 있습니다.
- 에러 처리(네트워크 오류, 잘못된 날짜, 빈 결과 등)가 없어, 응답 형식이 다르면 `KeyError`/`IndexError`가 날 수 있습니다.
- 제목 비교는 완전 일치(`==`)라서 띄어쓰기나 표기가 다르면 찾지 못합니다.
- docstring 스타일이 두 함수 간에 서로 다릅니다 (첫 번째는 "받는 것/돌려주는 것", 두 번째는 서술형 + 사용 예시).
